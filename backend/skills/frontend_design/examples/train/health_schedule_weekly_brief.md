# 示例:健康作息方案 + 产物美化(健康周报)

## 用户请求

我最近总是熬夜加班,白天没精神,请给我一份科学可行的作息改善方案。另外,我这边有一份本周工作周报的草稿,想请你美化成一页可视化简报,便于向上级汇报。

## 助手响应

好的,两件事:① 健康作息方案(科学建议,不构成诊疗意见);② 周报美化为一页可视化简报。先出方案,再美化。

### 一、作息改善方案(参考"清和"健康管理常识)

目标:建立稳定的睡眠节律,逐步改善日间精力。

| 时段 | 建议 | 说明 |
|------|------|------|
| 07:00 | 固定起床 | 周末偏差 ≤1 小时,稳定生物钟 |
| 09:00-12:00 | 高效工作窗口 | 精力峰值期处理难点任务 |
| 12:30 | 午间小憩 20-30 分钟 | 不宜超过 1 小时,避免进入深睡 |
| 13:00-17:00 | 低强度任务+走动 | 每坐 1 小时起身 3-5 分钟 |
| 21:00 后 | 减少屏幕蓝光 | 手机调夜间模式,避免剧烈运动 |
| 22:30 | 睡前准备 | 灯光调暗,复盘明日计划 |
| 23:00 | 入睡 | 目标 7-9 小时睡眠 |

要点:
- 熬夜后**不要**用周末补觉超过 1 小时(打乱节律);
- 咖啡因下午 2 点后减量;
- 若长期入睡困难或白天嗜睡明显,建议咨询专业医师/睡眠门诊。

### 二、周报美化为一页可视化简报

收到草稿后,我按"目标场景=向上级汇报"处理为**简报形式**(标题层级 + 数据可视化 + 结论先行),生成 `outputs/weekly_brief.html`:

```
结构:
1. 标题:本周工作简报(2026-W31)
2. 核心指标卡片:任务完成率 / 关键交付 / 风险项(3 张统计卡)
3. 进度可视化:条形图(各项目完成度)+ 甘特式时间线(关键节点)
4. 结论区:三条要点 + 下周计划
```

设计说明:
- 配色遵循设计系统 token(--text-primary/#1e293b、成功 #059669、警告 #d97706);
- 移动端单列堆叠,桌面端三栏指标卡 + 图表;
- 简报遵循"结论先行":第一屏即核心结论。
