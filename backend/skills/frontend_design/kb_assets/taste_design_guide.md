# 清和 · Taste 设计品味指南（Taste Skill 裁剪适配版）

> 版本：v1.0 | 场景：frontend_design（生活健康与美学设计）
> 来源：github.com/Leonxlnx/taste-skill（MIT，75k+ stars）—— design-taste-frontend v2 主技能 + soft-skill 高端柔和变体，按清和场景裁剪
> 适配说明：清和输出为**原生 HTML/CSS**（无 Tailwind/React 运行时），原文 Tailwind 语法一律译为 CSS 语义；默认取向为 soft 变体（柔和、克制、留白、有呼吸感的生活美学）。
> 用途：frontend_design 会话 auto_retrieve 自动注入 / search_knowledge 按需检索。

## 1. 设计读取（动手前必读）

动手写任何 HTML 前，先"读懂需求"——多数 AI 设计差是因为跳过了这一步直接套默认审美。

- **读信号**：页面/产物类型（健康打卡页？演示报告？计划清单？）、用户使用的氛围词（"素雅/温暖/清爽/高级"）、受众（给自己看？分享给家人？）、既有品牌资产（是否要沿用 FlowSpace 设计系统 token）
- **输出一行 Design Read 再动手**："此产物定位：生活美学 · 柔和温暖，配色走暖米色系，排版走大留白 + 温和圆角"
- **需求模糊时只问一个问题**，不连环追问；能推断就直接声明 Design Read 并动手

## 2. 三旋钮（清和默认值，对话可调）

三个 1-10 参数决定整个产物的气质，每个布局/动效/密度决策都受其约束：

| 旋钮 | 默认 | 含义 |
|---|---|---|
| `DESIGN_VARIANCE` | **4** | 布局实验性：4=克制规整（生活美学以稳妥为主，不追求不对称艺术感） |
| `MOTION_INTENSITY` | **3** | 动效深度：3=轻柔（hover 过渡 + 滚动浮现，不做磁吸/滚动驱动重效） |
| `VISUAL_DENSITY` | **3** | 信息密度：3=大留白（每屏信息少而精，呼吸感优先） |

- 用户说"更素雅/更极简"→ VARIANCE 降 1、DENSITY 降 1；"更活泼/更现代"→ VARIANCE 升 1-2；"更精致/更高级"→ 参考 §4 质感规则
- **不要**让用户编辑文件——调参发生在对话里，你根据描述自行调整

## 3. 反 AI 默认纪律（绝对禁止清单）

出现以下任何一项，产物即"塑料味"失败：

- ❌ AI 紫渐变、居中 hero + 深色网格背景
- ❌ 三张等大的功能卡一排、千篇一律的网格
- ❌ 全屏玻璃拟态（到处 backdrop-blur）
- ❌ 默认字体堆叠（中文场景尤其忌：正文全用系统默认无衬线 + 无层级）
- ❌ 1px 灰色边框、"硬投影"（shadow 生硬不弥散）
- ❌ 无限循环微动画、抖动、光效
- ❌ 页面内所有区块同构（应该：信息卡/时间线/对比表/图表混合使用）

## 4. 设计工程纪律

### 4.1 排版
- **字体层级**：大标题（强对比）/ 正文 / 注释三级分明；标题用字重 500-600 显层级，正文行高 1.6-1.8
- **中文场景**：优先系统中文字体栈（"PingFang SC", "Microsoft YaHei"）；标题可用衬线（宋体系）营造生活美学质感，正文保持无衬线可读
- **字号节奏**：4/8px 倍数体系（12/14/16/20/24/32/40…），不出现随意数值
- **行长控制**：正文每行 45-75 字符，长文本用 `max-width: 65ch`

### 4.2 色彩
- **60-30-10 法则**：主色 60%（背景/大面积）、辅助 30%（内容区）、强调 10%（CTA/关键数据）
- **对比度**：正文与背景 ≥ WCAG AA（4.5:1）；大字号标题可放宽到 3:1
- **清和默认配色（soft Editorial Luxury 取向）**：暖米底 `#FDFBF7` / 深咖啡文字 `#3E342F` / 鼠尾草绿点缀 `#8A9B8E` / 留白为主；健康主题避开荧光与高饱和
- **全页主题锁定**：同页只走一套配色，亮/暗不混用（除非明确要求双主题）

### 4.3 布局
- **间距体系**：4/8px 倍数；区块间距 ≥ 48px（`padding: 64px+` 让页面呼吸）
- **响应式**：<768px 一律单列降级（`width:100%; padding:16px`）；禁止 `height:100vh`（用 `min-height:100dvh` 防 iOS 跳动）
- **布局多样化**：产物 >3 个区块时至少 2 种布局形态（如：信息卡网格 + 时间线 + 大标题章节）
- **眉标**：大标题前可加微型胶囊标签（小字号、字距 0.2em、圆角全包）提升精致感

### 4.4 卡片与质感（soft 变体要点）
- **双层嵌套**：卡片 = 外容器（浅底 + 细边框 + 大圆角）+ 内核心（独立底色 + 内侧高光），营造"器物感"而非平面贴纸
- **阴影**：柔和弥散（`box-shadow: 0 8px 24px rgba(0,0,0,0.06)`），禁生硬 `0 2px 4px rgba(0,0,0,0.3)`
- **圆角**：大卡片 16-24px，按钮全圆（`border-radius: 999px`）
- **按钮**：主 CTA 全圆 + 充足内边距（12px 20px+）；箭头图标嵌套进独立圆形小容器（按钮内再套圆）

### 4.5 动效（轻柔档）
- **只用 `transform` 和 `opacity`**——禁动画 `top/left/width/height`（布局抖动 + 性能差）
- **过渡曲线**：自定义 `cubic-bezier(0.32, 0.72, 0, 1)`，禁裸 `linear`/`ease-in-out` 默认
- **滚动浮现**：元素进入视口做轻量 fade-up（`translateY(16px)+opacity 0→1`，800ms）；用 IntersectionObserver，禁 `window.addEventListener('scroll')` 连续计算
- **尊重** `prefers-reduced-motion`：用户偏好减弱动效时全部禁用动画
- **blur 约束**：`backdrop-filter` 仅用于吸顶/弹层，绝不用于滚动容器或大面积内容

### 4.6 状态与无障碍
- 交互元素 **hover / focus / active 三态齐全**（focus 可见焦点环）
- 键盘可达：按钮/链接语义化，表单 label 关联 input
- 图片 alt 文本；图标按钮 aria-label；装饰图 `aria-hidden`
- 表单：错误提示 + 成功反馈文案，不静默失败

## 5. 交付前检查（Pre-Flight，输出前逐项过）

- [ ] 无 AI 默认模板痕迹（紫渐变/居中三卡/全屏玻璃/默认字体堆叠）
- [ ] 配色 60-30-10 且正文对比度达标（≥4.5:1）
- [ ] 4/8px 间距体系、区块留白充足（≥48px）
- [ ] 响应式：<768px 正确降级单列，无横向滚动
- [ ] 动效只用 transform/opacity + 自定义曲线，尊重减弱动效
- [ ] hover/focus/active 状态齐全、键盘可达
- [ ] 整体气质："用心设计的生活美学产物"，而非"套模板的网页"

## 附：风格速查

| 需求词 | VARIANCE | MOTION | DENSITY | 取向 |
|---|---|---|---|---|
| 默认/素雅 | 4 | 3 | 3 | 暖米 + 大留白 |
| 更精致/高级 | 4 | 4 | 2 | 增加衬线标题、弥散阴影、微动效 |
