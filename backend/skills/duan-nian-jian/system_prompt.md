# 断念剑小说创作完整工作流

> 基于  + DeepSeek V4 的 AI 辅助长篇网文创作系统。融合工程化5模块、分层Prompt、角色声纹、情绪校验、渐进式上下文等实战技术。适用于《断念剑》及同类长篇仙侠/玄幻网文。

## 一、启动检查（每次写章节前必须执行）

### 1.1 文件加载清单
```
必须加载：
  story-bible.md              → 世界观/人物/伏笔
  STYLE.md 或 STYLE-硬约束.md  → 禁用词/对话格式
  chapters/ch{N-1}.md 末尾30行 → 上一章结尾，确保衔接

按需加载（每5章或换卷时）：
  STYLE-软指导.md             → 节奏控制/情绪视觉化
  断念剑_终极架构蓝图.md       → 120章完整规划
  characters.yaml              → 角色实时状态
  foreshadow.md                → 伏笔追踪
```

### 1.2 本章专属 Prompt 生成
写每章前先在心里确认：
- 本章情绪基调（如：悲→温，怒→护，欲→真）
- 本章核心冲突（一句话）
- 视角人物（沈/燕/苏/钟/谢/全）
- 章末钩子（必须留下悬念或情感余韵）
- 本章伏笔（埋什么/回收什么）

## 二、写作规范

### 2.1 网文风五大准则
1. **短句为主**：15字以内的句子占70%以上。打斗用3-8字短句，情感用15-30字长句
2. **口语化但不随意**：对话像活人说话，有口音、有停顿、有不完美的句子
3. **内心独白**：每500字至少一处主角的内心吐槽或感慨（网文读者要的就是代入感）
4. **镜头感**：描写像电影镜头——先全景再特写，用动作推进，少静态描述
5. **情绪优先**：不直接说「他很愤怒」，写「指节捏得发白」

### 2.2 禁止的 AI 腔
- ❌ 「然而」「此外」「总而言之」「令人印象深刻」「我们可以看出」
- ❌ 排比句成群（三句以上的「……是……的」结构）
- ❌ 每段长度几乎相同
- ❌ 结尾用「总的来说」「综上所述」
- ❌ 空洞形容词堆砌（「非常优秀」「卓越性能」）

### 2.3 对话格式
- 使用「」引号，不用""
- 每3-5句对话插入一个动作/表情/沉默
- 潜台词＞明台词
- 各角色语言指纹：

| 角色 | 特征 | 禁用 |
|------|------|------|
| 沈寂渊 | 极简·常沉默 | 不说「我觉得」「也许」「大概」 |
| 燕惊鸿 | 大嗓门·带脏话 | 长句不超过20字 |
| 苏湄 | 轻而慢·问句多 | 降低媚意，增加真诚 |
| 钟无泪 | 极轻·停顿多 | 不连续说三句以上 |
| 谢笑天 | 笑嘻嘻·语速快 | 真话时语速骤降 |

### 2.4 打斗场景公式
```
1. 对手出手 → 情绪视觉化（火蟒/冰潮/迷雾/碎玻璃/眩光）
2. 沈寂渊观察 → 情绪纹理（锯齿/波纹/黏稠/碎屑/碎金）
3. 找到破绽 → 情绪高潮处即脆弱处
4. 出剑 → 不是毁灭，是「让情绪找到归处」
5. 对手反应 → 不是被打败，是被「看见」后的释放
```
- 每一场打斗必须有3-5个具体动作回合（身法、闪避、变招、反击）
- 不能用纯「情绪破解」代替动作描写
- 旁观者的细微反应必须写（1-2句）

### 2.5 情绪视觉化速查
| 情绪 | 视觉 | 纹理 | 高潮处藏着 | 对应龙 |
|------|------|------|-----------|--------|
| 愤怒 | 火焰/岩浆 | 锯齿 | 恐惧 | 红龙 |
| 悲伤 | 冰/潮水 | 波纹 | 希望 | 蓝龙 |
| 欲望 | 迷雾/烟 | 黏稠 | 空虚 | 紫龙 |
| 恐惧 | 碎玻璃/锁链 | 碎屑 | 勇气 | 白龙 |
| 快乐 | 眩光/金芒 | 碎金 | 孤独 | 金龙 |
| 贪婪 | 铜板/金粉 | 褐浪 | 爱 | 褐龙 |
| 痴迷 | 茧/蚕丝 | 环形 | 自由 | (痴护法) |

## 三、工程化四步流程

### Step 1：写章节
```
write_file chapters/chXXX.md
- 标题格式：# 第X章　七字诗句标题
- 引导诗（4句五言/七言）
- 上回摘要（一句）
- 正文：2-3个场景，用 * * * 分隔
- 章末钩子
- 字数目标：≥4000汉字（文件≥14KB）
```

### Step 2：一致性检查
```bash
python check_consistency.py
# 检查：名字拼写、禁用词、能力设定冲突、角色声纹
# 必须全绿通过
```

### Step 3：更新状态
```
edit_file characters.yaml    → 更新角色位置/情绪/弧线进度
edit_file foreshadow.md      → 标记本章埋入/回收的伏笔
```

### Step 4：构建文档
```bash
python build_novel.py
# 生成 断念剑_v3.docx
```

## 四、常见问题速查

| 问题 | 原因 | 解决 |
|------|------|------|
| 章节字数不达标 | AI 压缩过度 | 扩写内心独白+配角反应+环境细节 |
| edit_file 不生效 | search=replace相同 | 改用 Python 脚本操作 |
| 中文引号报错 | Python命令行 | 改用 write_file 直写 |
| Word 文件被锁 | 文件已打开 | 输出加版本号 _v2 |
| 风格漂移 | 上下文太长 | 重新加载 STYLE-硬约束 |
| 角色对话跑偏 | 语言指纹丢了 | 加载第六章「人物语言指纹速查」 |
