## 1. 财务指标口径说明

### 1.1 盈利能力

| 指标 | 口径 | 注意点 |
|------|------|--------|
| 毛利率 | (营收-营业成本)/营收 | 同行业比较，跨行业不可比 |
| 净利率 | 净利润/营收 | 注意一次性损益与非经常性项目 |
| ROE | 净利润/股东权益 | 杜邦分解：ROE=净利率×总资产周转率×权益乘数 |
| ROIC | 税后营业利润/投入资本 | 排除杠杆影响，衡量经营本身回报 |

### 1.2 成长性

| 指标 | 口径 | 注意点 |
|------|------|--------|
| 营收增速 | (本期-上期)/上期 | 区分内生增长与并表/涨价 |
| 净利润增速 | 同上 | 警惕低基数导致的假高增长 |
| 自由现金流 | 经营现金流-资本开支 | 优于利润，防"纸面利润" |

### 1.3 估值

| 指标 | 口径 | 使用场景 |
|------|------|---------|
| PE | 市值/净利润 | 有稳定盈利的成熟公司 |
| PB | 市值/净资产 | 周期股、金融股 |
| PS | 市值/营收 | 亏损但高增长公司 |
| 股息率 | 每股分红/股价 | 价值型公司长期收益锚 |
| PEG | PE/盈利增速 | <1 相对低估（需谨慎） |

**估值分位**：与自身 5-10 年历史 PE/PB 区间对比（当前分位 >80% 偏贵，<20% 偏便宜），且与行业横向比较。

### 1.4 现金流与质量

- 经营现金流净额长期 > 净利润 → 利润质量高
- 应收账款增速显著高于营收增速 → 收入质量存疑
- 存货周转下降 + 毛利率上升 → 警惕压货

## 2. 宏观周期判断框架

### 2.1 核心宏观指标

| 指标 | 反映 | 数据来源 |
|------|------|---------|
| GDP 增速 | 总需求 | EDB 宏观数据 |
| PMI | 制造业景气（荣枯线 50） | EDB |
| CPI / PPI | 通胀压力 | EDB |
| 社融 / M2 | 信用扩张 | EDB |
| 利率（LPR/国债收益率） | 资金成本 | EDB / 新闻 |

### 2.2 周期定位四步

1. **货币周期**：宽信用（社融回升）→ 利好成长；紧信用 → 防御
2. **库存周期**：主动补库（需求好）→ 顺周期占优；被动去库 → 底部布局
3. **估值周期**：全市场 PE 分位判断股债性价比（股债利差）
4. **情绪周期**：新发基金遇冷/成交低迷 → 逆向机会；全民开户 → 警惕泡沫

## 3. 资产配置与交易纪律

### 3.1 配置比例原则

- 核心-卫星：核心仓（指数/宽基）60-70% + 卫星仓（行业/个股）30-40%
- 股债平衡：风险偏好决定股债比例（保守 30:70 / 均衡 50:50 / 进取 70:30）
- 单一行业 ≤ 20%，单一标的 ≤ 10-15%，留 5-10% 现金缓冲
- 定期再平衡：每季度或偏离目标 ±5% 时执行

### 3.1.1 风险档 → 战略配置映射（由 risk_profiling.md 驱动）

> 下列约束是组合引擎的**输入上界**。实际建议不得突破；突破须显式说明理由或调回。

| 风险档 | 战略股:债 | 权益上限 | 单标的上限 | 现金缓冲 |
|--------|-----------|----------|------------|----------|
| 保守 | 30:70 | 40% | 5% | 15% |
| 稳健 | 40:60 | 55% | 8% | 10% |
| 平衡 | 50:50 | 70% | 10% | 8% |
| 进取 | 70:30 | 85% | 15% | 5% |
| 激进 | 85:15 | 95% | 20% | 3% |

**向下修正**（取更保守者）：`horizon`≤1年 → 权益上限 -15pct；`loss_tolerance`=-10% → 单标的上限 -3pct 且权益上限 -10pct；`liquidity_need`=高 → 现金缓冲 +5pct。修正后现金缓冲 > 权益上限时，提示进一步下调权益暴露。

### 3.2 交易纪律（白圭核心）

- **止损位**：单标的 -8%~-15% 触发，机械执行不犹豫
- **止盈纪律**：目标价/估值达历史高分位时减仓，不贪最后一段
- **逆向思维**："人弃我取、人取我与"——恐慌抛售时关注基本面未破坏的优质资产
- **克制贪婪**：不追涨停、不满仓、不加杠杆；每次操作前问"若下跌 20% 能否承受"
- **记录复盘**：每笔交易记录买入逻辑与退出条件，定期复盘纠偏

### 3.3 风险提示模板

每份投资建议必须包含：
1. 市场风险（系统性回撤）
2. 个股/行业风险（基本面恶化、政策变动）
3. 流动性风险（小市值/低成交）
4. 免责声明：以上不构成投资建议，市场有风险，投资需谨慎

### 3.4 组合体检指标定义（code_execution 计算口径）

组合体检必须由 `code_execution`（pandas/numpy）计算，白圭只解释不编造。指标口径：

- **行业暴露**：各行业市值 / 总市值。单一行业 ≤ 20%（见 §3.1）。
- **个股集中度（HHI）**：`Σ(个股权重²)`，越接近 1 越集中；前三大标的占比单独列示。单标的 ≤ 风险档上限（§3.1.1）。
- **相关性矩阵**：取各持仓收益率序列（iFinD `stock_highfreq_quotes`），算 Pearson 相关系数矩阵；识别"假分散"（高相关标的堆砌）。
- **再平衡偏离**：`目标权重 − 当前权重`，正=需加仓、负=需减仓；乘以当前总市值得买卖额。
- **最大回撤 / VaR 近似**：用组合日波动率 σ 近似，`1日95% VaR ≈ 1.65×σ×组合市值`；历史最大回撤用持仓区间收益率序列峰值到谷值落差估算。注明"估算非真实回测"。
- **现金缓冲**：现金 / 总市值，须 ≥ 风险档下限（§3.1.1）。

### 3.5 再平衡触发规则

- 任一标的权重偏离目标 ±5%，或行业暴露超 20%，或现金缓冲低于风险档下限 → 触发再平衡。
- 定期再平衡：每季度末核对一次（与 §3.1 一致）。
- 再平衡动作清单：列出每标的具体买卖额、止损位（绑定 `loss_tolerance`）、执行优先级（先降超限、后补现金缓冲）。

## 4. 持仓分析模板

### 4.1 个股分析五步

1. **生意**：商业模式、护城河（品牌/网络效应/成本/转换成本）、行业空间
2. **财务**：近 3-5 年营收/净利/ROE/现金流趋势
3. **估值**：当前 PE/PB 与自身历史分位、行业对比
4. **催化与风险**：业绩催化、政策风险、竞争格局变化
5. **结论**：买入/持有/卖出 + 目标仓位 + 止损位

### 4.2 组合体检

- 各行业暴露占比（是否过度集中）
- 个股相关性（是否"假分散"）
- 最大回撤承受力与现金缓冲
- 再平衡触发检查
