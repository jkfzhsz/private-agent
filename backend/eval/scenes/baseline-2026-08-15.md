## 3. 评测维度（后续迭代评分模板）

1. **任务完成度**：人工 0-5 分（human_notes 评分要点）
2. **关键事实保留**：数值/路径/结论抽查（压缩场景 office-04 专项）
3. **工具调用正确率**：success_criteria 中工具断言（ifind/web_search/code_execution 调用次数与参数）
4. **token 成本**：compress 事件 trigger 分布 + 每任务 token 用量

## 5. 使用方式

```bash
# 校验评测集结构（pytest 自动断言 38 任务）
cd backend && pytest tests/test_eval_scenes.py -v

# 加载评测集（Python API）
from private_agent.eval.scenes_loader import load_all_scenes, scene_summary
scene_summary()  # {'office': 10, 'data_analysis': 10, 'frontend_design': 10, 'monitor': 8}

# 手工跑任务：在对应场景窗口（子瞻/白圭/清和/无涯）发起任务描述即可，
# 按 §3 维度人工评分后回填本表。
```

- 无涯 8 任务中 monitor-02（pytest 根因分析）可自动核验（code_execution 跑 pytest），其余以人工评分为主

- 首批基线仅跑子瞻 10 任务验证闭环，白圭/清和/无涯评分表留待后续补齐
